# Content Creation Prompt #3: False Cognates (French-English)

**Project**: OffGrid English - Offline-First English Learning for Cameroon
**Created for**: ESL Educators / Content Creators
**Date**: October 28, 2025

---

## Purpose

Alert learners when **English words look similar to French words but have different meanings**, preventing common misunderstandings and communication errors.

When students encounter these tricky words in questions, a "⚠️ False Cognate Alert" badge will appear, explaining the difference and helping them avoid the mistake.

## What You Need to Provide

For each false cognate pair, provide:

1. **English word**
2. **French word** (that looks similar)
3. **French meaning** (what the French word actually means)
4. **English meaning** (what the English word actually means)
5. **Example sentence** (showing correct English usage)
6. **Common mistake** (how French speakers misuse it)
7. **Memory trick** (optional - helps students remember)

---

## Template

```
═══════════════════════════════════════════════════════════
FALSE COGNATE #1: ACTUALLY / ACTUELLEMENT
═══════════════════════════════════════════════════════════

English Word: actually
French Word: actuellement

French Meaning:
"Actuellement" in French means "currently" or "at present" (right now)
Example (French): "J'habite actuellement à Yaoundé" = "I currently live in Yaoundé"

English Meaning:
"Actually" in English means "in fact" or "really" (used to correct or emphasize truth)
Example (English): "I thought he was from Douala, but actually he's from Bamenda."

Common Mistake:
❌ French speaker says: "I am actually in Yaoundé" (meaning "I am currently in Yaoundé")
✅ Should say: "I am currently in Yaoundé" or "Right now, I am in Yaoundé"
✅ Correct use of "actually": "Actually, I prefer living in Yaoundé to Douala."

Memory Trick:
Remember:
- "Actually" = "En fait" (not "actuellement")
- "Currently" = "Actuellement" (not "actually")

If you want to say "right now," use "currently," not "actually"!

Cameroonian Context Example:
✅ "Currently, I'm working at the Ministry of Education." (actuellement = currently)
✅ "Actually, I got this job last year, not this year." (en fait = actually)
```

## Detailed Examples

### Example 1: ASSIST / ASSISTER

```
═══════════════════════════════════════════════════════════
FALSE COGNATE #2: ASSIST / ASSISTER
═══════════════════════════════════════════════════════════

English Word: assist
French Word: assister

French Meaning:
"Assister" in French means "to attend" or "be present at"
Example (French): "J'ai assisté à la réunion" = "I attended the meeting"

English Meaning:
"Assist" in English means "to help" or "give support to"
Example (English): "Can you assist me with this task?"

Common Mistake:
❌ French speaker says: "I will assist the meeting tomorrow" (meaning "attend")
✅ Should say: "I will attend the meeting tomorrow"
✅ Correct use of "assist": "Can you assist me in organizing the meeting?"

Memory Trick:
Remember:
- "Assist" = "Aider" (to help)
- "Attend" = "Assister à" (to be present at)

If someone needs help, you ASSIST them.
If there's a meeting, you ATTEND it.

Cameroonian Context Example:
✅ "I attended the conference at MINEDUB office." (assister = attend)
✅ "The secretary assisted the director with the report." (aider = assist)
```

### Example 2: LIBRARY / LIBRAIRIE

```
═══════════════════════════════════════════════════════════
FALSE COGNATE #3: LIBRARY / LIBRAIRIE
═══════════════════════════════════════════════════════════

English Word: library
French Word: librairie

French Meaning:
"Librairie" in French means "bookstore" (a shop where you BUY books)
Example (French): "J'ai acheté ce livre à la librairie" = "I bought this book at the bookstore"

English Meaning:
"Library" in English means "a place to BORROW books for free"
Example (English): "I borrowed this book from the university library."

Common Mistake:
❌ French speaker says: "I bought this book at the library"
✅ Should say: "I bought this book at the bookstore"
✅ Correct use of "library": "I'm going to the library to study and borrow some books."

Memory Trick:
Remember:
- Library = Bibliothèque (BORROW books, FREE)
- Bookstore = Librairie (BUY books, PAY)

If you PAY money for a book → Bookstore (librairie)
If you BORROW and RETURN → Library (bibliothèque)

Cameroonian Context Example:
✅ "I study at the University of Yaoundé library every evening." (borrow books)
✅ "I bought my textbooks at the bookstore near campus." (buy books)
```

### Example 3: DEMAND / DEMANDER

```
═══════════════════════════════════════════════════════════
FALSE COGNATE #4: DEMAND / DEMANDER
═══════════════════════════════════════════════════════════

English Word: demand
French Word: demander

French Meaning:
"Demander" in French means "to ask" (polite request)
Example (French): "Je demande l'heure" = "I ask for the time"

English Meaning:
"Demand" in English means "to insist strongly" (forceful, not polite)
Example (English): "The workers demanded higher salaries." (strong insistence)

Common Mistake:
❌ French speaker says: "Can I demand you a question?" (meaning "ask")
✅ Should say: "Can I ask you a question?"
✅ Correct use of "demand": "The customer demanded a refund because the product was broken."

Memory Trick:
Remember:
- "Demand" = "Exiger" (strong, forceful)
- "Ask" = "Demander" (polite request)

If you're being POLITE → ASK (demander)
If you're being FORCEFUL → DEMAND (exiger)

Cameroonian Context Example:
✅ "May I ask you where the Ministry office is?" (polite = ask)
✅ "The union demanded better working conditions." (forceful = demand)
```
